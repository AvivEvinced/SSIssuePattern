Site Scanner Issue Taxonomy

Every ticket in the “Site Scanner Ticket Classification” ground-truth sheet, re-read from its Zendesk thread and split into issue families (by root cause) and sub-issues (by mechanism and fix path). Detectability shows whether a Coralogix log pattern could plausibly flag the sub-issue.

Log detectability:yesmaybeno GT class: 1scan failure 20 pages 3failed pages 4crawl irregularity 5other

The GT classes describe the symptom the customer saw. The same root cause shows up under several symptoms (for example, a WAF block appears as 0 pages, failed pages or a low page count), so the investigator should map symptom → candidate sub-issues → log check.

The decision path the investigator can follow for a crawl or scan complaint. Each leaf is a sub-issue ID from the tree. Run the cheapest discriminating check first.
